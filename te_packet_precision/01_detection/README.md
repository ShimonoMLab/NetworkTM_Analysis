# Packet erasures and directed-dependence detection (2026-11-24)

## 実行と再現
Python 3、NumPy、pandas。`python experiment.py` → `python payload_loopback.py` → `python analyze.py`。summary.csv は全100条件（完全記録4条件を含む）の集計、per_seed_te.csv は評価用乱数条件別のTE、loopback.csv はペイロード確認、paired_bootstrap.csv は検出率差の対応付き再標本化。原神経データは使用していない。合成データを用いた予備的研究であり、独立再現と査読を経た成果ではない。

## 1. 方法
人工信号 X_t ~ Bernoulli(0.30)、Y_t ~ Bernoulli(0.16+0.18Y_{t-1}+bX_{t-1})。40対は b=0、40対は b=0.08。1ステップを1 msと解釈。較正用12独立乱数、評価用12独立乱数、各80対。各条件で同じ信号・欠落乱数を使用して方式間を対応させた。80対を同じパケットの欠落で扱うため、480対は独立な通信試行ではない。信号条件は単一の結合強度・発火率であり、実神経記録の代替ではない。

1パケットは10時点×160チャネルの200バイト。4データパケットを1ブロックとし、送信時刻0,10,20,30 ms、仮想片道遅延20 ms。XORパリティは40 ms送信、60 ms到着。NACKは50 ms送信、70 ms到着、最初の欠落1パケットのみ70 ms再送、90 ms到着。各データの生成時刻からの期限で採否を判定。独立欠落の確率0.1、連続欠落は6仮想スロット上の2状態マルコフ過程（欠落継続確率0.65、定常欠落確率0.1）。連続欠落の時間間隔は等間隔の実ネットワーク時間を表さない。未使用スロットにも潜在欠落を割り当てる。受信順序・遅延・欠落は論理モデルで、待ち行列やブロックをまたぐ帯域競合は未モデル化。

全方式で4データ当たり最大6パケット相当の共通上限。フィードバックも200バイトにパディングし、各データグラムに8バイト独自ヘッダ、IPv4+UDPを28バイトとして計236バイト。最大1416バイト/ブロック（40 msの生成周期に対し平均上限283.2 kbit/s相当）。これはブロックごとの通信量予算であり、実時間の帯域保証、同一実消費通信量、リンク層通信量を意味しない。rate列は8000時点の平均通信量比。短い観測長の実通信量を個別算出していない。XORは常に5、NACKは最大6、再送なしは4パケット。NACK/パリティの再送や複数欠落への対処は未実装。

TEは I(X_{t-1};Y_t|Y_{t-1}) の経験的8セル度数から計算。欠落位置考慮法は t,t-1の双方が期限内に受信された時点のみ使用。比較としてゼロ補完。各方式、観測長、欠落種、期限、処理別に較正用帰無480対の99パーセンタイルを閾値とし、評価データとは分離。有限較正数・共有欠落・複数比較のため、名目1%は保証されない。評価FPRは条件により1%を超える。完全記録の閾値を使い回す比較も集計。

## 3. 数理深化：受信率ではなく履歴の有効割合
M_tを時点tが期限までに受信される指標、W_t=M_t M_{t-1}。lag-1 TEの有効割合 f=E[W_t]=1-2p+P(M_t=0,M_{t-1}=0)（pは時点ごとの欠落確率、定常の場合）。独立パケット、長さh、欠落率pなら、同一パケット内の隣接対が(h-1)/h、境界対が1/hなので f=((h-1)/h)(1-p)+(1/h)(1-p)^2。h=10,p=.1でf=.891、再送なしの実験値.8909と整合。これは受信率と有効履歴割合の関係についての式であり、必要観測時間を保証しない。Mが信号と独立なら選択された三変量の母集団分布は保存されるが、有限標本バイアスや欠測の依存構造に起因する分散は別に扱う必要がある。

必要観測時間近似 T*≈T*_0/f の診断：検出率80%に達する時点を1000/2000時点の点間線形補間で参考値として計算（両点で評価FPRが1%以下の条件）。完全記録約1805時点、独立欠落100msの再送なし1881、XOR1801、NACK1855。完全記録値/f の予測は順に2026、1880、1877。粗い補間で不確実性が大きく、モデルの棄却や検出時間短縮の実証ではない。特にXORが完全記録より短い点推定は較正・標本の揺らぎを含む。

次に、代替仮説下のTE推定量の影響関数 ψ_t を用い、欠測重み W_t に対する長期分散 L=Σ_k Cov(W_t ψ_t,W_{t+k} ψ_{t+k}) を推定する。比率推定量の漸近分散候補 L/(T f²)（定常性、混合条件、正則性等が必要）。帰無TE=0では一次のデルタ法が退化し得るので、帰無の閾値はブロック・ブートストラップまたは置換で別途較正する。新規性候補は、有効履歴と長期分散を通信の期限・通信量制約と組み合わせた方式選択則。この段階では長期分散モデルの数値検証は未実施。後続の段階02〜04を参照。

## 4. UDPペイロード試験
1台のPC内の2 UDPソケット、IPv4ループバック。実際にデータ、XORパリティ、パディングされた逆方向NACK、再送ペイロードを送受信し、受信側で人工欠落を適用。実時刻ではなく上記の論理時刻で期限を判定。独立・連続欠落×3方式×2期限の12条件、各800データパケットで、期限内受信マスクと全有効ペイロードが元データと一致し、最大通信量制約内であることをassertで確認。これは実装整合性確認であり、物理通信性能測定ではない。大規模TE集計は高速化のため同一論理モデルのマスクで計算。ループバックは1乱数条件での照合。
