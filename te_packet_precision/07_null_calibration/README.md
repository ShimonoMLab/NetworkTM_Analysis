# Independent null calibration and power (v75)

Run `python null_power.py`, then `python plot_null_power.py`. All signals are generated; no recordings. The source is Bernoulli(0.2), and the binary target has conditional probability 0.05 + 0.6 Y(t-1) + b X(t-1). b=0, .025, .05, .10. Record lengths 4,000 and 12,000 samples; 10-sample packets and a shared mask. Packet loss is independent of the signal (0%, 10% independent, 30% independent, 30% with lag-one packet correlation 0.8). The estimator uses a 0.5 count pseudocount per category. Per length, 800 null calibration trajectories (seed 75100+i) are separate from 800 evaluation trajectories per b (seed 75200+10*i+j). The 95th percentile is selected with NumPy's `higher` quantile; strict greater-than defines rejection. Complete-record thresholds and separately calibrated estimator/mask thresholds are contrasted.

At 12,000 samples, correlated 30% loss: false-positive rate 13.0% for mask-aware TE using the complete-record threshold, 84.5% for zero fill with that threshold, 6.5% for mask-aware TE with a matched threshold. Wilson intervals are conditional on this calibration sample (10.8–15.5%, 81.8–86.8%, 5.0–8.4%, respectively, rounded); calibration uncertainty is not propagated. The matched threshold uses knowledge of the synthetic null and erasure regime. It is not an implemented surrogate method for unknown empirical networks. At b=.025, matched mask-aware detection at 4,000/12,000 samples was 56.375/96.75% (complete), 43.125/90.375% (iid30), 42.0/91.375% (burst30). No monotonic superiority or minimal observation time is inferred from two sample lengths. All individual rates, sample sizes, thresholds, valid fractions and conditional Wilson intervals are in `null_power.csv`. Replicates are independent within a condition, but methods and scenarios share signals. The intervals are pointwise, not simultaneous, and do not establish controlled error for new settings.

This is a new synthetic validation of a calibration problem, not a new statistical theorem or real-network benchmark. No raw data included.
